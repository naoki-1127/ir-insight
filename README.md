# IR Insight（MVP）

## 🧭 コンセプト（最重要）

IR Insightは、企業の決算資料（PDF）をアップロードし、
**テキスト抽出・翻訳・時系列比較を簡単に行えるツール**です。

以下の3つの体験にフォーカスします：

- PDFをアップロードできる
- テキスト抽出＆日本語翻訳ができる
- 同一企業の過去資料と比較できる

👉 この3点に絞ることで、最小構成でも価値を提供します。

---

## 🚀 MVPでできること

### 1. PDFアップロード

- 決算短信・決算説明資料などのPDFをアップロード
- 企業と紐づけて管理

### 2. テキスト抽出 & 翻訳

- PDFからテキストを抽出
- 英語 → 日本語に翻訳
- セクション単位で保持

### 3. 時系列比較（コア機能）

- 同一企業の過去ドキュメントを一覧表示
- 年度・四半期で並び替え
- 前年同期との比較が可能

## 🗂️ データ構造（MVP）

### Document

- タイトル
- ファイルURL
- 企業ID
- 会計年度（fiscalYear）
- 四半期（quarter）
- 種別（periodType: Q / FY）

### DocumentContent

- 英語テキスト
- 日本語テキスト
- 順序インデックス

### ビジネスパーソン

## ❌ MVPでやらないこと
