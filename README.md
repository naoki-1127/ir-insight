# Growth Earnings Screener

## 概要

米国グロース株の決算情報をもとに、**成長率と事業構造を素早く把握できるスクリーニングアプリ**。

ユーザーが気になる銘柄を登録し、決算資料（PDF）のURLを貼り付けるだけで、
重要な情報を自動抽出・整理します。

---

## コンセプト

> 「決算を読む」のではなく、「成長と事業を一瞬で理解する」

- 決算資料の読解コストを削減
- 成長率と事業内容にフォーカス
- 自分が気になる銘柄だけを管理

---

## ユーザーフロー

### 1. 銘柄登録

- ティッカーまたは企業名で検索
- ウォッチリストに追加

---

### 2. 決算資料URLの貼り付け

- 決算PDFのURLを入力
- 例：Earnings Release / 10-Q など

---

### 3. 自動解析

アップロードされた資料から以下を抽出：

- 売上
- 売上成長率（YoY）
- セグメント情報
- ガイダンス（可能な場合）
- 経営コメント

---

### 4. 可視化

解析結果をシンプルに表示：

- 成長率とその変化
- 事業ごとの成長
- 投資家向け要約

---

## 主な機能

### 1. ウォッチリスト管理

- 自分が追いたい銘柄のみ管理
- ノイズのない投資環境

---

### 2. 決算データ抽出

- PDFからテキストを解析
- 売上・成長率・セグメントを自動取得

---

### 3. 成長分析

- 売上成長率（YoY）
- 前回比較による変化（加速 / 減速）

---

### 4. セグメント分析

事業ごとの成長を構造化：

例：

- クラウド：+45% 🔥
- 広告：+12%
- その他：-5%

---

### 5. 3行サマリー

投資家向けに要点を整理：

1. 成長ドライバー
2. リスク要因
3. 現在のトレンド（加速 / 減速）

---

## 技術構成（想定）

### フロントエンド

- Vue 3
- Tailwind CSS

### バックエンド

- Node.js
- Prisma
- PostgreSQL

### データ処理

- PDF → テキスト抽出
- LLMによる構造化解析
- 正規表現による数値抽出

```ts id="w2h7sl"
Company - id - ticker - name;

Earnings -
  id -
  companyId -
  date -
  revenue -
  revenueGrowth -

  guidance -
  summary -
  trend(accelerating / decelerating);
```

## MVPスコープ

- PDF URL入力機能
- 売上・成長率の抽出

## ポジショニング

- 情報量を増やすアプリではない
- 深い分析をするツールでもない

👉 **「理解コストを下げる」ことに特化**

## まとめ

本アプリは、決算資料を読む手間を削減し、
**「成長率」と「事業構造」を一瞬で理解できる体験を提供する。**

👉 投資判断のスピードを上げるためのツール
